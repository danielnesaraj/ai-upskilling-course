# Curriculum

This directory contains the durable lesson work packets for the course.

## Format

Each lesson is a compact textbook/work packet: enough explanation to build a correct mental model, derive the important mechanics, implement them, and know what evidence demonstrates understanding. It is deliberately not a full academic textbook.

Each lesson should contain, as applicable:

1. Objectives and prerequisites
2. Core concepts
3. Intuition
4. Mechanism and mathematics
5. Derivations/proofs worth knowing
6. Common misconceptions
7. Implementation / experiments
8. Exercises
9. Acceptance criteria
10. Evidence required
11. Questions you should be able to answer
12. Evaluation criteria
13. References

## Accuracy rule

Factual or mathematical claims must be supported by a reliable reference where appropriate. Derivations should either be shown or explicitly identified as assumptions/definitions. When sources disagree, prefer primary sources, standard textbooks, official documentation, or peer-reviewed work and state the distinction.
