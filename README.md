# AI Upskilling Course

A hands-on journey from backend engineering to AI engineering.

## Goal

Build enough AI understanding to **explain, implement, debug, evaluate, and improve** AI systems—not merely use LLM APIs and frameworks.

## Approach

- Learn from first principles: math → ML → neural networks → deep learning → transformers → LLMs → applications.
- Understand mechanisms before frameworks.
- Learn by implementing, experimenting, debugging, and evaluating.
- Build one evolving AI application throughout the course.
- Prefer free, local, and open-source tooling.
- Treat completion as different from mastery.

## Curriculum

Math → ML → neural networks → deep learning → transformers → attention → tokenization/embeddings → LLM training/inference → prompting → structured outputs → RAG → vector search → tool calling → agents/workflows → MCP → evaluation → reliability → observability → fine-tuning/model serving → current AI ecosystem.

## Working Principles

1. **Use it → explain it → implement it → debug it → evaluate and improve it.**
2. Do not hide behind frameworks. Understand what they do underneath.
3. Prefer experiments and evidence over intuition.
4. Diagnose failures systematically: model, prompt, context, retrieval, or application architecture.
5. Do not add technology merely to demonstrate it.

## Project Artifacts

- `curriculum/` — durable lesson work packets and learning artifacts.
- Implementation, experiments, tests, and evidence live in the repository.
- Course state and evaluations are tracked separately in the course tracker.
